## Apply the same persona to an installed model

Install Ollama and a supported base model first. Then, for example:

```powershell
python scripts/create_profile.py --base qwen3.5:4b-q4_K_M --name foreman-agent:latest --context 65536 --output 2048
```

The 64K setting above belongs to the tested 4B agent profile. The new 35B experiment uses a bounded 2K context. Do not reuse 64K for large models on a 16GB PC. Profile creation reuses installed weights and changes the system prompt; it performs no gradient updates.

A catalog entry is not an architecture-specific training recipe. The existing recipe supports only Qwen3-Coder-30B; applying it unchanged to all 50 models is unsupported.
